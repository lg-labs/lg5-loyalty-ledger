TASK-012 executing against the live deployment surfaced three defects
that pre-merge CI + file evidence had **not** caught — the canonical
justification for the post-merge live-probe TASK existing in the first
place.

| Bug | Severity | REQ impact | Root cause | Remediation | Fix commit | Hotfix PR |
|-----|----------|-----------|------------|-------------|------------|-----------|
| **BUG-1** | P1 | REQ-009 (SHA), REQ-020 (PR#) | `c-integration.yml` `docs-build-pages` and `docs-build-firebase` steps did not inject `COMMIT_SHA`, `BUILD_TIME`, `PR_NUMBER` into the build env; `docs/site/.vitepress/config.ts` defines fell back to `'dev'` / placeholder values. Footer rendered `Built from dev`. | Added `env:` blocks injecting `COMMIT_SHA: ${{ github.sha }}` + `PR_NUMBER: ${{ github.event.pull_request.number }}` + shell-side `BUILD_TIME="$(date -u +%Y-%m-%dT%H:%M:%SZ)"` export to both build steps. | `3eaaaf2` | #8 |
| **BUG-2** | cosmetic | none (docs accuracy) | `tasks.md` and `verify-report.md` referenced `lglabs-pentagon.github.io/lg5-loyalty-ledger/` (wrong org); actual repo owner is `lg-labs`. | Corrected references to `lg-labs.github.io/lg5-loyalty-ledger/` across spec files. | `3eaaaf2` | #8 |
| **BUG-3** | P2 | REQ-020 (short SHA) | `SourceStateFooter.vue` rendered the full 40-char `__COMMIT_SHA__`; REQ-020 mandates the *short* commit identifier. | `const sha = fullSha.length > 7 ? fullSha.slice(0, 7) : fullSha;` in `SourceStateFooter.vue:9`. | `60673eb` | #8 |

**How they were caught:** TASK-012 step (c) — visual inspection of the
source-state footer on each live surface — flagged BUG-1 immediately
(`Built from dev` vs expected short SHA). BUG-3 surfaced from the same
inspection once BUG-1 was fixed (full SHA rendered instead of 7-char).
BUG-2 surfaced while drafting the TASK-012 evidence block (cited URL
returned NXDOMAIN on the wrong org).

**Hotfix delivery:** PR #8 (`fix/004-task-012-hotfix`) squash-merged
as `79ef3b0` on 2026-05-12. Main CI run `25728095799` (post-hotfix)
all-green; all 3 deploy jobs ✅; preview correctly `skipped` on push
to main.

**Process value:** these bugs are exactly the class of defect that
the spec's choice to gate live deploys to `push && main` (ADR-002 +
ADR-003) was designed to surface via a sanctioned post-merge probe
rather than pretend to catch pre-merge. The 🟡-override→✅-verified
trajectory is the intended lifecycle.
